Step 2 · Correlation Board

Which events tell one connected story?

What you are doing: Decide which logs should be investigated together. Put a log in the evidence chain when it meaningfully helps explain the suspicious sequence. Put it in Context when it is valid machine data but does not help explain this incident.

Suspicious sequence

1 · What happened first?→ 2 · What happened next?→ 3 · What followed?

Context / not part of this sequence

Nothing placed here yet.
Place a valid but unrelated log here.

How do I decide?

Ask: Does this event involve the same account, source, system, or developing behavior? Does its timing help explain what happened before or after? Does connecting it add useful evidence?

Example: failed logins followed by a successful login for the same account and source have a meaningful relationship. Two unrelated events occurring close together do not automatically belong in the same chain.

Step 1 · Requirement Weighting

What should drive the decision?

Step 2 · Deployment Trade-off Board

Interrogate each option

Open each deployment model. Decide whether it is a strong fit, possible but compromised, or a weak fit for Harborline. Your notes will carry into the final decision.

Standalone

One Splunk instance performs ingestion, indexing, search, and visualization.

Distributed

Multiple Splunk instances perform one or more specialized functions.

Cloud

Similar to distributed, but hosted and managed by a third-party cloud provider.

Step 3 · Executive Decision

Make the call

Now commit to one deployment. Your recommendation should emerge from the requirements and trade-offs you just evaluated.

Learning Transfer

Carry the mental model into Splunk.

When you next open Splunk, connect interface actions to the system behind them: machine data originates somewhere, forwarders can collect it, indexers make it searchable, and the search experience helps you investigate and turn data into operational insight.

Navigate

Recognize the web-based interface, search bar, results, navigation, dashboards, and visualization editors. Splunk browser access uses port 8000 in the lesson.

Configure thoughtfully

Account and preference settings matter. In particular, aligning the time zone helps timestamps make sense during analysis.

Extend when needed

Splunk apps package dashboards, reports, and other content; add-ons provide additional functionality such as inputs and parsers for specific data sources.
